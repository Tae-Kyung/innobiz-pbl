# PRD: PBL 컨설팅 보고서 자동생성 시스템

## 1. 배경 및 목적

AI특화공동훈련센터 PBL 사업의 컨설턴트가 기업을 방문하여 AX(AI Transformation) 진단 및 컨설팅을 수행하고, 그 결과를 서식3(수행일지), 서식4(결과보고서), 서식5(훈련 운영계획서)로 작성해야 한다. 이 보고서 작성 업무를 Claude API를 활용하여 자동화한다.

## 2. 사용자

- **주 사용자**: PBL 컨설턴트 (1인)
- **사용 시나리오**: 기업 방문 후 면담 내용을 시스템에 입력하면, AI가 서식에 맞는 보고서를 자동 생성

## 3. 핵심 기능

### 3.1 기업 관리
- 기업 등록 (기업명, 사업자등록번호, 업종, 주요 제품/서비스, 조직도 이미지, 담당자 정보)
- 기업 목록 조회 및 상세 보기
- 기업별 진행 상태 대시보드 (어느 서식까지 완료했는지)

### 3.2 서식1 - AX 수준진단 점수 관리
- 7개 영역(전략/조직/인재/문화/데이터/인프라/거버넌스) × 문항별 1~5점 입력
- 영역별 평균, 전체 평균 자동 계산
- 100점 환산 및 Lv1~5 자동 판정
  - (전체 평균 - 1) / 4 × 100
  - Lv1: ~30점, Lv2: 31~50점, Lv3: 51~70점, Lv4: 71~85점, Lv5: 86~100점
- 레이더 차트 시각화

### 3.3 서식2 - AX 세부진단 (인터뷰 관리)
- 기업 정보 자동 연동 (서식1에서)
- 설문 결과 표시 (서식1 연동)
- 7개 영역별 인터뷰 질문/답변 입력
  - 공통 질문 + AX 진행단계별 추가 질문 (서식2 PDF의 질문 풀 내장)
  - 질문 선택 → 답변 텍스트 입력
- 워크플로우 재설계 입력 (부서/직무/책무별 As-is, To-be, 필요 교육훈련)
- AI 기반 종합 분석결과 생성 (영역별 1~3개 핵심 포인트 + 후속 활동)

### 3.4 서식3 - 컨설팅 수행일지 생성
- 8회차 수행일지 자동 생성
  - 1차: 서식1 검증 결과 (7개 영역 주요결과)
  - 2~8차: 영역별 인터뷰 결과 (전략/조직/인재/문화/데이터/인프라/거버넌스)
- 회차별 메타데이터 입력 (회의일시, 방법, 장소, 참석위원)
- 입력된 인터뷰 내용 기반으로 AI가 수행일지 본문 생성

### 3.5 서식4 - 컨설팅 결과보고서 생성
- 서식1~3의 모든 데이터를 종합
- AI가 생성하는 항목:
  - AX 진단 컨설팅 개요 (기업정보, 진단활동)
  - 설문 결과 분석 (영역별 주요결과 + 후속활동)
  - 인터뷰 핵심 과제 도출 (인프라/데이터/인재 관점)
  - 직무별 추천 AI 훈련과정 (As-is → To-be → 추천 훈련과정)
  - 차상위 Lv 진입을 위한 우선순위 과제
  - [붙임1] 영역별 설문 결과
  - [붙임2] 영역별 인터뷰 결과 (질문/답변 표)
  - [붙임3] 워크플로우 재설계 및 훈련과정 설계

### 3.6 서식5 - 훈련 운영계획서 생성
- 서식4의 추천 훈련과정을 기반으로 생성
- AI가 생성하는 항목:
  - I. 훈련과정 개요
  - II. 컨설팅 개요 (과정개발 필요성, 주요 활동, 주요 결과)
  - III. 훈련 요구분석 (기업 현황, 훈련대상 업무 선정/분석, 훈련환경)
  - IV. PBL 운영계획 수립 (운영계획서, 훈련 교과목 프로파일, 평가 계획)
- 일부 항목은 사용자 직접 입력 (훈련생 명단, 시설/장비 등)

### 3.7 보고서 내보내기
- 생성된 보고서를 마크다운으로 편집 가능
- Word(.docx) 또는 PDF 내보내기

## 4. 비기능 요구사항

- **배포**: Vercel
- **DB**: Supabase (PostgreSQL)
- **인증**: Supabase Auth (이메일/비밀번호, 1인 사용이므로 단순)
- **AI API**: Claude API (claude-sonnet-4-6)
- **반응형**: 데스크톱 우선 (보고서 작성 특성상)
- **한국어 UI**

## 5. 데이터 모델 핵심 엔티티

- `companies` - 기업 정보
- `diagnoses` - 서식1 진단 결과 (32문항 점수)
- `interviews` - 서식2 인터뷰 (영역별 질문/답변)
- `workflow_redesigns` - 서식2 워크플로우 재설계
- `consulting_logs` - 서식3 수행일지 (8회차)
- `consulting_reports` - 서식4 결과보고서
- `training_plans` - 서식5 훈련 운영계획서

## 6. 페이지 구조

```
/ (대시보드 - 기업 목록 + 진행상태)
/companies/new (기업 등록)
/companies/[id] (기업 상세 - 탭 구조)
  ├── 기본정보 탭
  ├── 서식1 (진단 점수 입력)
  ├── 서식2 (인터뷰 입력)
  ├── 서식3 (수행일지 생성/편집)
  ├── 서식4 (결과보고서 생성/편집)
  └── 서식5 (훈련계획서 생성/편집)
/settings (API 키 설정 등)
```

## 7. AI 프롬프트 전략

각 서식 생성 시 Claude API에 다음을 포함:
1. **시스템 프롬프트**: 서식의 구조와 작성 가이드라인 (서식 PDF에서 추출한 규격)
2. **컨텍스트**: 해당 기업의 모든 입력 데이터 (진단점수, 인터뷰 내용, 워크플로우 등)
3. **출력 형식**: 서식의 각 섹션별 마크다운 구조

프롬프트는 서식별로 분리하여 `/prompts/` 디렉토리에 관리.

## 8. MVP 범위

Phase 1 (MVP):
- 기업 등록/관리
- 서식1 점수 입력 + 자동 계산
- 서식2 인터뷰 입력
- 서식3 수행일지 AI 생성
- 서식4 결과보고서 AI 생성

Phase 2:
- 서식5 훈련 운영계획서 AI 생성
- Word/PDF 내보내기
- 서식6 훈련 결과보고서

## 9. 예산 구조 참고
- 컨설팅: 8회 방문, 예산 240만원
- 훈련 운영: 예산 100만원
